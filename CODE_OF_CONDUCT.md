# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Criticise code, not
people. This is a small project people work on in their spare time.

## Not welcome

Harassment, insults, discrimination, sexualised language, publishing someone's
private information, or repeatedly demanding attention after being asked to
stop.

## Scope

Everywhere the project happens: issues, pull requests, discussions, and any
space where you are representing the project.

## Enforcement

Report a problem to the maintainer, [@aryasadeghy](https://github.com/aryasadeghy),
through a GitHub private security advisory on this repository (it is the only
private channel GitHub gives us) or a direct message. Reports are handled
privately.

Depending on what happened, the response is a private word, a public
correction, a temporary block, or a permanent one. The maintainer's decision is
final; nobody is owed a second chance after deliberate harm.

This document is a deliberately short paraphrase of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, which applies in full where this text is silent.
